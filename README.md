# ملتقى أبناء قصاصين الأزهار — الموقع الرسمي
## Moltaca Elazhar — Official Community Website

الموقع الرقمي الرسمي لـ **ملتقى أبناء قصاصين الأزهار** بمركز أولاد صقر، محافظة الشرقية، جمهورية مصر العربية. تأسس في **25 مارس 2012**.

الموقع يقدّم الهوية المؤسسية للمبادرة بأسلوب تحريري راقٍ مستوحى من مبادئ **Google Material 3** ويبرز مسيرة التكافل المجتمعي، صالونات الشعر والأدب، معارض الفنون التشكيلية، تكريم أوائل الطلاب، والتغطيات الصحفية القومية.

---

## 🎨 الهوية البصرية ونظام الألوان

- **اللون الأساسي:** الأسود الملكي المؤسسي (`#0B0B0B`)
- **خلفية الصفحات:** الأوف وايت التحريري الدافئ (`#F7F7F5`)
- **اللون الثانوي:** الأخضر الزيتوني الريفي (`#66734A`)
- **لون التمييز:** الذهبي التكريمي الدافئ (`#C6A15B`)
- **الخطوط:** خطوط عربية حديثة فائقة الوضوح (`Cairo` و `IBM Plex Sans Arabic`)
- **الاتجاه:** دعم كامل وفوري لليمين إلى اليسار (`RTL`)

---

## 📂 أقسام الموقع

1. **الرئيسية (Home):** الهوية الرسمية، الختم المعتمد، إحصائيات الإنجاز، وبيان الرؤية المجتمعية.
2. **عن الملتقى (About):** قصة التأسيس في 25 مارس 2012، الركائز والقيم، والخط الزمني لمحطات العطاء (2012 – 2024+).
3. **المواهب والأنشطة (Activities):** بطاقات تفاعلية مصنفة (الشعر والأدب، الفنون التشكيلية، التكافل الإنساني، تكريم المتفوقين، النشاط الميداني) مع نافذة تفاصيل منبثقة.
4. **التغطيات الصحفية (Press):** بطاقات صحفية توثق النشر في كبريات الصحف القومية والمحلية (اليوم السابع، الوطن، الدستور، البوابة نيوز، أخبار الشرقية).
5. **الأرشيف المرئي (Gallery):** معرض صور مقسم مع تجربة **Lightbox** لعرض الصور بدقة عالية، وقسم للأفلام الوثائقية وReels.
6. **التواصل والروابط الرسمية (Contact):** قنوات التواصل الرسمية عبر فيسبوك، وتساب، والموقع الجغرافي.

## 🚀 التشغيل المحلي

المشروع مصمم كواجهة أمامية ثابتة (Static Web App) سريعة وخفيفة دون الحاجة إلى قاعدة بيانات أو سيرفر خلفي معقد:

```bash
# الانتقال إلى المجلد
cd "e:\El Moltaqa app\web app"

# تشغيل خادم محلي
npm start
# أو مباشرة عبر npx
npx serve . -p 3000
```

افتح المتصفح على: `http://localhost:3000`
